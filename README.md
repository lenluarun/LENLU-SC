## ⚡ SYSTEM OVERVIEW

LENLU SC is an immersive, hardware-accelerated command console designed to bridge the gap between human-readable keyboard scripts and target host executable packages.

The console features:
* 🛠️ **DuckyScript Linter & Compiler**: Translates keystroke injection scripts into compiled AutoIt3 executables with real-time error checking and multi-language export (PS1, Bash, Python).
* 🧠 **Neural Synthesis Lab**: Multi-model AI payload generation (Groq, OpenAI, Anthropic) with voice dictation controls and stealth timing auto-calibrators.
* 📡 **Network Surveillance HUD**: Real DNS resolutions, service scanners (SSH, HTTP, HTTPS, DB, Cache), local WebSocket sweepers, BLE beacon tracking, and microphone frequency analyzers via Web Audio API.
* 🔌 **Hardware WebUSB Flasher**: Directly streams payloads to Flipper Zero (BadUSB), Rubber Ducky, or Arduino controllers using chunked transmissions.
* 🔓 **Web Crypto Hash Cracker**: Performs real-time dictionary attacks and brute-force hash-cracking utilizing Web Worker multi-threading.
* 📱 **Native Android App**: Edge-to-edge WebView wrapper with notch support, 5 daily push notifications, native BLE/WiFi scans, and full cyberpunk theme integration.

## 🛠️ CORE CHAMBERS

### 1. 💻 Integrated Payload Workbench
* **DuckyScript Compiler**: Translates keystroke inject scripts (`DELAY`, `STRING`, `GUI`, `ENTER`, `CTRL`, etc.) into AutoIt3 (`.au3`) and multi-language (PS1, Bash, Python) export.
* **Interactive Linter**: Continuously evaluates typed scripts inside the editor, flagging warnings and syntax anomalies directly inside the IDE log panel.
* **DuckyScript 3.0 Functions**: Full support for `FUNCTION`, `END_FUNCTION`, variable arguments, and recursive script blocks.
* **Persistent Cache**: Keeps your current workspace, active code, compiler logs, and open tab selections safe across browser sessions via IndexedDB.
* **60+ Template Library**: Pre-built payload templates for recon, persistence, pranks, automation, and credential auditing.

### 2. 🧠 Neural Synthesis Lab
* **Multi-Model Uplink**: Connects to AI models (Groq/Llama, OpenAI/GPT, Anthropic/Claude) via user-configured API keys in the Settings panel.
* **Offline Mode**: Rule-based DuckyScript generator works without any API key — generates payloads from natural language prompts locally.
* **Voice Dictation**: Integrated Web Speech APIs allow converting voice commands into functional scripts.
* **Stealth Calibrator**: Automatically scales script delay metrics per AI preset (Stealth / Troll / Recon / Persistence).
* **AI Copilot**: Forge AI assistant that can write scripts, navigate views, run scans, and execute IDE commands on command.

### 3. 📡 Network Surveillance HUD
* **DNS Resolution**: Resolves IP addresses and fingerprints hosts via Cloudflare's DNS-over-HTTPS (DoH) API.
* **Service Scan**: Fingerprints standard service layers across 21 common protocol ports with response-time heuristics.
* **BLE Beacon Tracker**: Simulated and real Web Bluetooth scans capturing RSSI, device name, MAC address, and estimated distance.
* **Subnet Sweep**: Async Class-C subnet scanner probing 25 hosts with visual IP chip grid output.
* **WebRTC Leak Check**: Safely queries RTC candidate tables to map out public and local network interfaces.
* **Speed Test**: Cloudflare-based download/upload speed test with animated gauge, latency, and jitter measurements.
* **Microphone Spectrograph**: Web Audio API FFT visualizer mapping ambient signal scans onto a WebGL canvas.

### 4. 🔌 WebUSB Hardware Flasher
* **Direct Flashing**: Connects via WebUSB (Chrome/Edge) to stream payloads to external hardware.
* **Handshake Protocol**: Implements a secure chunked transmission (`DUCK_READY` ➡️ `CHUNKS` ➡️ `DUCK_EXEC`).
* **Hardware Profile Registry**: Pre-loaded support for Rubber Ducky, Flipper Zero, and Arduino.

### 5. 🔓 Web Crypto Hash Cracker
* **Multi-Threaded**: Runs in isolated browser Web Workers to ensure 60 FPS UI performance during cracking.
* **Fast-Path Dictionary**: Checks target hashes against a built-in repository of common credentials.
* **Brute-Force Enumerator**: Brute-forces strings dynamically using customizable charsets (upper, lower, nums, symbols).

### 6. 📱 Android Native App (v4.0)
* **Edge-to-Edge Layout**: WebView draws behind status bar and navigation bar with dynamic safe area CSS variables (`--safe-top`, `--safe-bottom`).
* **Bottom Navigation Bar**: Fixed 7-tab bottom nav (Home, Dash, IDE, Neural, Tools, Vault, Config) visible on mobile — auto-syncs with top nav active state.
* **Logo Toggle Navigation**: Tap the LENLU SC logo (or hamburger icon) on mobile to toggle the top nav tabs open/closed.
* **Themed Radio Button Controls**: HUD Accent Color selector uses themed radio buttons with live color swatches instead of a dropdown.
* **Draggable AI Chatbot**: The floating Forge AI Copilot button and chat window can be dragged anywhere on screen (touch + mouse support).
* **Radio-Style Tool Selection**: Tools sidebar category buttons now display as radio-style indicators with active dot indicators.
* **Notch/Display Cutout Support**: `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` with programmatic status bar overlay.
* **5 Daily Push Notifications**: WorkManager-scheduled random Intel briefings, payload tips, and system status alerts — fires even when app is closed.
* **Reboot Persistence**: `BootReceiver` reschedules notifications automatically after device reboot.
* **Native BLE Scan**: Hardware-level Bluetooth LE scanner with RSSI data bridged to WebView via base64 JSON.
* **Native WiFi Scan**: `WifiManager` scan results with SSID, BSSID, signal level, frequency bridged to WebView.
* **Splash Screen**: Animated app icon splash screen via `SplashScreen` API.
* **Cyberpunk Theme**: Status bar transparent, white icons, matrix green accent, deep black backgrounds throughout.

## 🚀 UPLINK & DEPLOYMENT PROCEDURE

### 🌐 Web Console (Development & Production)

#### 1. Setup Dependencies
```bash
npm install
```

#### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` — the Vite dev server includes local API middleware for auth and content endpoints.

#### 3. Build for Production
```bash
npm run build
```
The build process compiles everything into a single, fully-inlined file at `src/dist/index.html` and automatically copies it to:
- Project root: `index.html`
- Android assets: `appp/src/main/assets/index.html`

> [!NOTE]
> The compiled `index.html` files are excluded from git (via `.gitignore`). Regenerate on demand with `npm run build`.

#### 4. Deployment on Vercel
The repository includes a [`vercel.json`](./vercel.json) configured for Vite builds:
1. Connect this repository to your Vercel project.
2. Vercel auto-detects `vercel.json` and sets build config.
3. Serverless API functions in `api/` are deployed automatically.

> [!WARNING]
> WebUSB, Web Crypto, and Speech Recognition require **HTTPS**. Vercel enables this by default.

#### 5. Environment Variables
Copy `.env.example` to `.env` and configure:
```env
MONGODB_URI=mongodb+srv://...           # Optional: MongoDB for persistent content storage
ADMIN_JWT_SECRET=your-secret-here       # JWT signing secret for admin panel
ADMIN_PASSWORD_LENLU=your-password      # Admin user 1 password
ADMIN_PASSWORD_MANISHA=your-password    # Admin user 2 password
```
